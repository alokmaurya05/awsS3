## Demo project  Connect to S3 Bucket and upload files using Spring Boot and AWS SDK for Java 17.
Add your AWS credentials in the application.properties file and run the application. You can upload files to your S3 bucket using the provided REST API endpoints.
## Requirements
For building and running the application you need:
JDK 17
Maven 3
